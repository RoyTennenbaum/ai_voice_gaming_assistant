# ai-voice-gaming-assistant

An in-game AI tactical assistant designed to provide real-time, hands-free answers to game knowledge queries without breaking gameplay flow or forcing players to alt+tab out of their game.  
Currently focused on **Warframe** item drops, farming locations, and relic rewards.

---

## 🎯 Scope & Purpose (MVP)

Warframe contains vast amounts of resources, locations, and mechanics, forcing players to constantly switch to external websites (Warframe Wiki, Overframe, Reddit). This project resolves that friction by providing an instant, natural-language query engine.
